# T2T_Pig
![8e04da01d7ab605e46bc97d536bdbd90](https://github.com/user-attachments/assets/11951118-6ffe-41c4-b63a-2025610dd9ec)


This repository provides codes that were developed, tested, and used in our published study:  
**“Two telomere-to-telomere pig genome assemblies and pan-genome analyses provide insights into genomic structural landscape and genetic adaptations”** (*iMeta*, 2025).  

I regard genome assembly as an iterative, data-driven process rather than a universal, one-size-fits-all protocol. For HiFi-based assemblies, it is often necessary to systematically evaluate multiple read combinations and sequencing configurations (e.g., HiFi-only vs. HiFi plus ultra-long ONT, or coverage/length-stratified subsets), as input characteristics can markedly influence contiguity, repeat resolution, and polishing outcomes. In parallel, I recommend closely tracking recent methodological advances and peer-reviewed studies, and integrating these insights—together with rigorous benchmarking—into a project-specific pipeline aligned with the target genome, sequencing design, and downstream analytical objectives.
